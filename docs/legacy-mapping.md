# Legacy Oracle (MOBILEMPLS) → PostgreSQL mapping

Source of truth for the new model: `backend/prisma/schema.prisma`.

## Documents: BLOB → server storage

- Bytes are written through `StorageProvider` (`backend/src/infrastructure/storage`). Default driver: local disk under `STORAGE_ROOT`. Switching to S3/MinIO = one new class.
- DB keeps: original name, verified content type (magic bytes), size, SHA-256, `storage_provider`, opaque `storage_key`, scan status, uploader, cancel info.
- Keys are generated by the server (`quotations/{quotationId}/{uuid}`); the user's file name is never used as a path.
- Download endpoint checks ownership, forces `attachment` + `nosniff`.
- Cancelling is a soft delete; add a retention job to purge files later.

### One-time migration of existing BLOBs

Write a script that reads each legacy image row, writes the bytes through `StorageProvider.put`, and inserts a `quotation_documents` row (map `IMAGE_CODE` → `document_types.code`, `STATUS/ACTIVE_STATUS` → `status`, `CANCEL_BY` → `cancelled_by`). Run it in batches and verify the SHA-256 after copying.
